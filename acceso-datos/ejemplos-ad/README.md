# 🗄️ Acceso a Datos (AD)

Este repositorio reúne las prácticas, ejercicios y actividades desarrolladas a lo largo de las distintas unidades didácticas del módulo de **Acceso a Datos** de **DAM** (Desarrollo de Aplicaciones Multiplataforma).

---

## 📁 Contenido del Repositorio

| Carpeta / Unidad | Descripción |
| :--- | :--- |
| **`Exception`** | Gestión avanzada de excepciones en Java para la manipulación y persistencia de datos. |
| **`Ficheros_Path_Streams_UD2`** | Manejo de archivos de texto y binarios usando las clases `Path`, `Files` y flujos de datos (`Streams`). |
| **`JDBC_UD3`** | Conexión y operaciones CRUD sobre bases de datos relacionales mediante la API de **JDBC**. |
| **`ORM_EntityManager_UD4`** | Mapeo Objeto-Relacional (ORM) con **JPA** y `EntityManager` para el manejo de entidades y persistencia. |
| **`PostgreSQL_ORDB_UD5`** | Trabajo con bases de datos objeto-relacionales (ORDB) implementadas sobre **PostgreSQL**. |
| **`MongoDB_UD6`** | Persistencia NoSQL y manipulación de documentos en **MongoDB**. |

---

## 🛠️ Tecnologías y Herramientas
* **Lenguaje principal:** Java
* **Bases de Datos Relacionales / Objeto-Relacionales:** PostgreSQL, MySQL/MariaDB
* **Bases de Datos NoSQL:** MongoDB
* **APIs / Frameworks:** JDBC, JPA / Hibernate (ORM)
