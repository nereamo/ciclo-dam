# 💻 Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)

Repositorio personal con las actividades, proyectos y apuntes desarrollados a lo largo del ciclo formativo **DAM**.

---

## 📚 Estructura del Repositorio

### 🟢 Primer Curso
* **`programacion/`**: Fundamentos de programación, POO y estructuras de datos en Java.
* **`entornos-desarrollo/`**: Control de versiones, UML y refactorización.
* **`sistemas-informaticos/`**: Configuración de sistemas, redes y virtualización.
* **`bases-datos/`**: Diseño relacional, SQL, triggers y procedimientos almacenados.
* **`lenguajes-marcas/`**: HTML5, CSS3, XML y JSON.

---

### 🔵 Segundo Curso
* **`acceso-datos/`**: Manejo de ficheros, persistencia, ORM (Hibernate) y bases de datos objeto-relacionales / NoSQL.
* **`desarrollo-interfaces/`**: Componentes visuales, diseño UI/UX, JavaFX, Qt y generación de instaladores/informes.
* **`programacion-multimedia/`**: Desarrollo de aplicaciones móviles nativas y multiplataforma (Android Studio / Flutter).
* **`servicios-procesos/`**: Programación multihilo, sockets, concurrencia y seguridad.
* **`sge/`**: Configuración, implantación y extensión de Sistemas de Gestión Empresarial (ERP/CRM).
